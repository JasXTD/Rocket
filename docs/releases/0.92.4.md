# Rocket 0.92.4

Insights for repository activity and pull requests, a more capable Agents workspace, Rust module maps, faster history views and security hardening. Available as portable packages for Windows, Linux, Apple Silicon macOS and Intel macOS.

## Highlights

- **Insights:** explore repository activity and pull request metrics, open PR drilldowns, filter by author or reviewer, compare trends and export reviewed CSV/JSON samples. Saved views remember the filters for each repository. Missing reviews and partial samples are identified instead of estimated.

- **Agents:** launch GitHub Copilot CLI alongside Claude Code, Codex and custom executables. Sessions are grouped by attention state, support exact-conversation resume where the provider allows it, and guide you through reviewing and integrating committed work. Reviewed executables, permissions, local changes and Stop controls retain their safeguards.

- **Repository maps:** inspect the modules within a Rust package and their dependencies without compiling or executing repository code. The People view uses a readable folder-by-person table; package details, compact drawers and navigation have clearer layouts. Rust macros and conditional compilation are not expanded, and this is not a function-call graph.

- **Faster history and long lists:** create, update or remove Git's commit-graph through Speed up history, with cancellation and measured timings. Long file/branch lists draw visible rows instead of every row. Fetch can update the index when enabled for that repository; commits and working files are preserved.

- **Interface improvements:** the Repository sidebar stays steady while loading or writing, status messages no longer shift the window, and Agents, PR discussions, Insights and translated Browse rows fit their panels more reliably. The egui/eframe 0.37 upgrade preserves Rocket's styling, Arabic text support, clipboard behavior and outline emoji fonts.

## Security and correctness

- **Stronger secret protection:** detect AWS access credentials, private JSON Web Keys and OAuth client secrets. The optional AI API-key guard also covers Bedrock keys. Multiline JWK formatting cannot evade scanning, and long scans remain cancellable. Existing Git history is checked when publishing, so old exposed credentials can still block a push.

- **History Index containment:** cleanup uses held directories, refuses redirected paths and preserves unknown files, hard-link peers, external locks and local changes. Chain reads are bounded before allocation, including files that grow while being read.

- **Safer agent launches:** Linux rechecks executable permission and `noexec`; macOS checks quarantine on source files, enclosing folders and bundles. Reviewed-byte binding remains enforced, and Windows retains its held-file protection.

- **Unix repository locking:** releasing an operation explicitly unlocks it even if a concurrently started child inherited a descriptor. Competing writers remain excluded; Rocket does not remove Git's locks.

- **Dependency maintenance:** update rustix to 1.1.6 and refresh the audited UI dependencies and notices. Insights rejects invalid/extreme timestamps rather than overflowing calendar calculations.

## Hosting fixes

Correct pagination and review-thread identifiers on GitHub/GitHub Enterprise, short commit IDs on Bitbucket Cloud, text previews and API versions on Azure DevOps, GitLab approval/merge reconciliation, and Gitea conversations and review requests. PR merge and discussion controls have clearer layouts. These adapters have focused mock-API coverage; live acceptance on non-GitHub accounts and Jira remains pending.

Each archive has a SHA-256 sidecar; `SHA256SUMS` lists all four archive hashes. Keep every bundled helper beside the application and compare your download against its checksum before use. Close Rocket and extract to a new folder instead of overwriting a running copy.

## Validation and limitations

Release qualification checks the merged source, enabled secret protection, local SSH-key leakage, package contents/checksums and affected regression tests. Native localhost MCP checks use temporary repositories and isolated profiles. Both Mac architectures use standard public GitHub runners; Windows and Linux are built locally with locked dependencies. This does not establish the absence of every bug or live interoperability with every hosting provider.

The macOS packages are ad-hoc signed, **not Developer-ID-signed or notarized**. Physical Mac acceptance remains pending, and these previews refuse in-app installation. An intermittent Intel spelling failure observed in 0.92.3 has not had a confirmed cause; focused startup diagnostics are retained and spelling remains part of package acceptance. Preview translations still need native-speaker and compact-layout review. Fresh Windows 11, broader Linux distributions and real non-GitHub/Jira accounts remain on the roadmap.

Rocket does not install AI CLIs or change their accounts. AI providers may need separate subscriptions. Existing repository files, credentials and SSH configuration are not changed by installing the portable package. Newer saved-state features may prevent an older Rocket build from reading that state; retain a backup before downgrading.

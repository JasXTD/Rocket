# Rocket 0.92.1

This release adds the Apple Silicon macOS preview and includes the latest
desktop fixes. Windows and Linux portable packages remain available.

## Changes

- **macOS preview:** native menus and Command shortcuts, system spelling for
  commit messages, Keychain-backed protected storage, system SSH, zsh terminal,
  repository notifications, and CJK/emoji fallbacks.
- **Isolated Mac Lua:** a hash-bound Pulley helper inside `Rocket.app`, with
  bounded memory, cancellation and parent-exit cleanup. Windows and Linux keep
  their existing native sandboxes.
- **Mac update groundwork:** verified downloads, cancellation and rollback are
  implemented; installation still requires Developer ID signing and notarization.
- **Search fields:** text and placeholders align vertically with their icons.
- **Bundled Git startup:** faster inventory and hashing without dropping any
  pinned-file verification; separate timing diagnostics help identify slow checks.
- **Security and recovery:** refuse symlinked Unix MCP fixture markers, preserve
  useful Keychain errors without losing unsaved Lua code, and retain the selected
  terminal shell when using isolated history.

## Packages

| Platform | Package | Requirements |
| --- | --- | --- |
| Windows x64 | `Rocket-0.92.1-windows-x64.zip` | Windows 10/11 x64; Git and required app-local runtimes are included. |
| Linux x64 | `Rocket-0.92.1-linux-x64.tar.gz` | glibc **2.43+**, a desktop session and installed Git. Built and tested in Ubuntu 26.04 WSL; older distributions are not compatible with this archive. |
| macOS Apple Silicon | `Rocket-0.92.1-macos-arm64-preview.zip` | macOS 15+ and installed Git; Intel Macs are not supported by this package. |

Extract into a new folder. Keep all helper executables and resources together.
Do not overwrite an app while it is running. Existing repositories, settings,
credentials and SSH keys are not included in these packages.

The **Mac package is a preview**: it is ad-hoc signed, not Developer-ID-signed or
notarized. It has passed Apple Silicon runner tests; physical Mac, IME/Retina and
normal-user shell/Keychain acceptance remain pending. This ZIP is for manual
installation and is deliberately not an in-app update archive. Rocket does not
disable Gatekeeper or relax its production update trust checks.

## Verify a download

Each archive has a matching `.sha256` file; the release also includes
`SHA256SUMS`. Compare the archive's SHA-256 with the published value before use.

PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 .\Rocket-0.92.1-windows-x64.zip
```

Linux:

```sh
sha256sum -c Rocket-0.92.1-linux-x64.tar.gz.sha256
```

macOS:

```sh
shasum -a 256 -c Rocket-0.92.1-macos-arm64-preview.zip.sha256
```

The extracted packages also contain inventories and per-file checksums. Checksums
detect mismatched bytes; they do not replace publisher signing or notarization.

# Rocket 0.92.3

Parallel local agent workspaces, an Intel Mac preview, expanded translations and
hosting discussions, and security hardening. All four portable packages use the
same source revision.

## Changes

- **Agents workspace:** run Claude Code, Codex or a custom executable in separate
  worktrees, with reviewed branches, commands and optional setup. Switch between
  terminals, changed files and session details; review diffs without stopping a
  process. Stop controls the owned process tree. Saved sessions do not restart
  automatically, and removal protects uncommitted work and keeps the branch.
- **Executable-launch security:** bind Agents and setup launches to the reviewed
  executable bytes. Unix uses private verified snapshots; Windows retains its
  executable lock through startup and cleanup. Changed setup inputs need another
  review, and cancellation removes partial snapshots.
- **Credential-helper security:** fresh private request folders and stricter Git
  discovery boundaries prevent a pre-created or enclosing repository from
  injecting credential helpers. Existing logins, Git configuration and keys are
  preserved.
- **Mac worktrees and Intel:** enable safe native worktree publication on macOS
  and provide separate Apple Silicon and Intel packages with matching Lua
  helpers. Existing-file, stale-preview, Unicode and cancellation checks remain.
- **Languages:** extend all ten preview translations across advanced settings,
  hosting, history, conflict, recovery and repository workflows. User content and
  command arguments are preserved, with English fallback where needed.
- **Hosting discussions:** reviewed replies and resolution for GitLab, Bitbucket
  Cloud and Server/Data Center, and Azure DevOps Services and Server. Gitea adds
  review-comment resolution; its stable API does not provide thread replies.
  Changed revisions refuse writes and uncertain submissions retain recovery data.
- **Jira extension:** validate required fields and paginated creation metadata
  against the documented Cloud v3 API. Live Jira acceptance remains pending.

## Packages

| Platform | Package | Requirements |
| --- | --- | --- |
| Windows x64 | `Rocket-0.92.3-windows-x64.zip` | Windows 10/11 x64; Git and required app-local runtimes included. |
| Linux x64 | `Rocket-0.92.3-linux-x64.tar.gz` | glibc **2.43+**, a desktop session and installed Git. Built in Ubuntu 26.04 WSL; older distributions need a source build. |
| macOS Apple Silicon | `Rocket-0.92.3-macos-arm64-preview.zip` | macOS 15+, Apple Silicon and installed Git. |
| macOS Intel | `Rocket-0.92.3-macos-x64-preview.zip` | macOS 15+, Intel x64 and installed Git. |

Extract into a new folder and keep helpers/resources together. Do not overwrite
a running app. Repositories, account settings, credentials and SSH keys are not
included in these packages. Agent commands use your account's normal permissions;
they are external programs, not sandboxed Lua extensions.

Both **Mac packages are previews**: ad-hoc signed without Developer ID signing or
notarization. Physical Mac, IME/Retina and normal-user shell/Keychain acceptance
remain pending. Install them manually; these ZIPs are not in-app update archives.
Rocket does not disable Gatekeeper or relax its update trust requirements.

## Scope of verification

The affected executable security, process lifecycle and Agents UI checks use
native Windows, Linux/WSL, Apple Silicon and Intel environments with temporary
repositories and synthetic processes. Native Mac qualification covers reviewed
executable substitution, setup handoff, cancellation, Unicode worktrees, first-click
Stop, compact layouts and protected local changes.

Hosting discussions use loopback mock APIs. These checks do not establish live
compatibility with non-GitHub hosts, Jira, or every external AI CLI. All ten
translations remain previews, with English fallback. Windows package acceptance
uses the existing Windows 10 host; it is not a fresh Windows 11 test.

## Verify a download

Each archive has a `.sha256` sidecar. `SHA256SUMS` lists all four archives.

```powershell
Get-FileHash -Algorithm SHA256 .\Rocket-0.92.3-windows-x64.zip
```

```sh
# Linux
sha256sum -c Rocket-0.92.3-linux-x64.tar.gz.sha256
# macOS: choose the sidecar for your architecture
shasum -a 256 -c Rocket-0.92.3-macos-arm64-preview.zip.sha256
shasum -a 256 -c Rocket-0.92.3-macos-x64-preview.zip.sha256
```

Compare with the published checksum before use. Extracted packages include file
inventories. Checksums verify bytes; they do not replace publisher signing.

# Rocket 0.92.2

Language preferences, saved appearance at startup, and expanded hosting reviews
and CLI workflows. Windows, Linux and Apple Silicon portable packages share the
same source revision.

## Changes

- **Languages:** select any of ten preview translations in Preferences → General.
  Rocket initially detects your system language, remembers explicit choices and
  falls back to English where a screen is unfinished. Git/identity, Terminal and
  AI draft settings now use the translation catalogs.
- **Startup appearance:** apply the saved theme, language and zoom before the
  first visible frame, without waiting for Git discovery.
- **Inline reviews:** single-line comments for GitLab, Bitbucket Cloud,
  Bitbucket Server/Data Center, Azure DevOps Services and Server, plus batched
  single-line reviews for Gitea. GitHub range comments remain supported. Preview
  the exact diff/revision; changed revisions refuse submission and uncertain
  results retain the draft for recovery instead of retrying a write.
- **CLI hosting:** account checks, PR/issue lists, details, creation, reviews and
  merging with JSON output, explicit environment credentials and required
  review fingerprints before writes.
- **Composed workflows:** reviewed `commit-push` and `branch switch-saved` in
  the CLI, with partial outcomes and recovery data. Localhost MCP exposes phases,
  commit/stash IDs, remote outcomes and cancellation.
- **GitLab search:** server-side title/description, author and assignee filters
  for merge requests and issues, with repository scope preserved across pages.
- **Mac hosting:** fix discovery of the trusted system `/usr/bin/curl`; ignore
  executable substitutions through PATH, SystemRoot or Git's install folder.

## Packages

| Platform | Package | Requirements |
| --- | --- | --- |
| Windows x64 | `Rocket-0.92.2-windows-x64.zip` | Windows 10/11 x64; Git and required app-local runtimes included. |
| Linux x64 | `Rocket-0.92.2-linux-x64.tar.gz` | glibc **2.43+**, a desktop session and installed Git. Built in Ubuntu 26.04 WSL; older distributions cannot use this archive. |
| macOS Apple Silicon | `Rocket-0.92.2-macos-arm64-preview.zip` | macOS 15+ and installed Git; Intel Macs are not supported. |

Extract into a new folder and keep helpers/resources together. Do not overwrite
a running app. Repositories, account settings, credentials and SSH keys are not
part of these packages.

The **Mac package is a preview**: ad-hoc signed, without Developer ID signing or
notarization. Physical Mac, IME/Retina and normal-user shell/Keychain acceptance
remain pending. Install it manually; it is not an in-app update archive. Rocket
does not disable Gatekeeper or relax its update trust checks.

## Scope of verification

Focused tests use temporary repositories and loopback mock APIs for hosting
requests, changed revisions, Unicode paths, authentication failures, cancellation,
uncertain writes and diagnostic privacy. Mock acceptance does not establish
real-service interoperability for non-GitHub providers. Preview translations are
not yet complete throughout the app. See [Hosting](../../HOSTING.md) and
[CLI](../../CLI.md) for command and provider-specific limits.

## Verify a download

Each archive has a `.sha256` sidecar. `SHA256SUMS` lists all three archives.

```powershell
Get-FileHash -Algorithm SHA256 .\Rocket-0.92.2-windows-x64.zip
```

```sh
# Linux
sha256sum -c Rocket-0.92.2-linux-x64.tar.gz.sha256
# macOS
shasum -a 256 -c Rocket-0.92.2-macos-arm64-preview.zip.sha256
```

Compare with the published checksum before use. Extracted packages also contain
file inventories. Checksums verify bytes; they do not replace publisher signing.

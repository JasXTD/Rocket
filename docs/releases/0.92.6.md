# Rocket 0.92.6

Rocket 0.92.6 updates bundled Git, adds five languages to Code Map’s Modules view, and speeds up portable updates. On Windows and Linux x64, choose **Help → Check for Updates** to update an existing installation. The Apple Silicon and Intel macOS previews are manual downloads.

## What changed

- **Patched Git.** Windows packages include Git for Windows 2.56.1.windows.1. Rocket checks installed and custom Git versions before opening or cloning a repository. Windows requires 2.56.1.windows.1 or later. Linux and macOS accept stable Git 2.56.1 or later, or the patched maintenance releases starting at 2.50.2, 2.51.3, 2.52.1, 2.53.1, 2.54.1 and 2.55.1 on their respective branches. Preferences identifies the update needed for your branch.
- **Code Map.** Map → Code → Modules now reads Java and Kotlin packages, C and C++ include relationships, and C# namespaces. Folder maps show links across projects. Rocket reads committed source without running a project build. Each read covers up to 512 packages, including empty ones.
- **Portable update progress.** While preparing to restart, Rocket shows completed and total files for checking the installation, checking the update and staging its files. Up to four files are processed in parallel. A staged file counts as complete after a successful SHA-256 readback. An upgrade started in 0.92.5 still uses the old progress display.
- **Bundled Git diagnostics.** Activity & Diagnostics can identify the phase and file position of a slow verification, including whether Stop was requested. The records omit file paths and contents.
- **Windows-managed updates.** An MSIX installation directs users to Windows or the Microsoft Store. All nine UI languages include the new update messages. The GitHub installer and ZIP use Rocket’s portable updater. Microsoft Store certification is separate from this release.

## Downloads

| Platform | Package | Requirements and updates |
| --- | --- | --- |
| Windows x64 | `Rocket-0.92.6-Setup-x64.exe` or `Rocket-0.92.6-windows-x64.zip` | Per-user installer or portable folder. Both include Git and the Windows runtimes. |
| Linux x64 | `Rocket-0.92.6-linux-x64.tar.gz` | glibc 2.43+, X11 or Wayland and supported system Git. In-app updates use this archive. |
| macOS Apple Silicon | `Rocket-0.92.6-macos-arm64-preview.zip` | macOS 15+ and supported Git. Install manually. |
| macOS Intel | `Rocket-0.92.6-macos-x64-preview.zip` | macOS 15+ and supported Git. Install manually. |

Choose the package for your platform and compare its SHA-256 with the published `SHA256SUMS`. For a manual portable installation, extract into a new folder and keep your repositories outside the application folder. The GitHub Windows installer is unsigned. The macOS previews lack Developer ID signing and notarization, which Rocket requires for an in-app Mac update.

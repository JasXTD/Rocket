# Rocket 0.92.7

Code Map can take you from a Rust module, an embedded file or a web asset to the line that references it. The viewer reads the commit shown on the map, so you can investigate an older revision while keeping your current edits open.

## Explore a connection

- **Rust declarations, imports and re-exports.** Select either file in **Map → Code → Folders** or **Modules**, then choose **Go to reference**. A grouped import opens on the chosen member. A glob opens on the star. Literal `include_str!` and `include_bytes!` references open on the macro call.
- **HTML and CSS assets.** Follow a page to its stylesheets, scripts and images, or select a shared asset to find its callers. Responsive image candidates, CSS imports and URLs lead back to the committed source, including when several links share a line.
- **Script and native dependencies.** Trace local PowerShell and Bash helpers, Lua modules and Rocket integration entry scripts. Follow GitHub Actions workflows to local scripts, actions and reusable workflows. Explore Objective-C and Objective-C++ header imports and Rust calls into native code.
- **Reference navigation.** Step between occurrences, copy a source location or return to the selected file on the map. Narrow windows switch between the list and the code. Dense folder maps limit drawing work and keep filenames readable when arrow counts would overlap.

## Git workflow fixes

- Full stash protects edits hidden by index flags. Branch Review keeps the selected branch when a tag has the same name.
- Partial staging handles legacy CRLF attributes and blank context lines. Staging new files and restoring binary data respect Git’s conversion settings.
- Conflict resolution recognizes custom marker widths and preserves Markdown heading underlines. Discard and recovery handle executable-bit-only changes on Linux and macOS.
- Moving a linked worktree preserves relative Git links. Rocket can also repair a linked worktree moved outside the app.
- Rebase and other operation-aware menus recognize idle and in-progress worktrees when you control Rocket through localhost MCP.

## Security and reliability

Unix recovery files and AI draft requests use private storage. Commit templates are confined to their selected scope. A shared import budget bounds Rust analysis across a map, and copied reference paths escape control characters. The macOS Lua helper updates Wasmtime to 50.0.2.

For a manual download, compare the package’s SHA-256 with its `.sha256` file or the combined `SHA256SUMS` in the release assets. Extract portable packages into a fresh folder and keep repositories outside that folder.

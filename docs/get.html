Get Rocket

Build Rocket from source on Windows x64.

Rocket is in development, at version 0.87.3. There is no public installer or download yet.
  1. 1

    Install the tools

    The Rust MSVC toolchain, 1.89 or newer, with Microsoft C++ build tools, and Git 2.46 or newer.

  2. 2

    Get the source

    git clone https://github.com/JasXTD/rocket.git
cd rocket
  3. 3

    Build it

    .\tools\Build-Local.ps1

    This builds the desktop app, the CLI and their helpers under target\release. Plain cargo build compiles too, but turns Lua extensions off.

  4. 4

    Start Rocket

    .\target\release\rocket.exe

    Help → Setup Guide walks you through a first local commit. Press F1 for the guide and Ctrl+K for the command palette.

What it uses

Windows x64The validated platform. Testing has focused on Windows 10.
GitA build from a fresh clone uses the Git you installed. HTTPS needs Git for Windows 2.56.0.windows.4 or newer; older builds stay on local and SSH.
Git Credential ManagerFor the supported browser sign-in flows.
Windows OpenSSHFor SSH keys and profiles.
Git LFS 3.8.1+Only for Git LFS operations.
Claude Code or CodexOptional, for AI drafts, review and resolve.

Moving a build? Keep every file from target\release together.

Current limits

  • Windows is the validated platform. Linux and macOS are not certified.
  • Live acceptance for hosts other than github.com is still unverified.
  • Partial diff and stash actions support specific text and file cases.
  • Jira has been tested against mock services, not a live server.
  • The AI conflict page has been tested with a stand-in program, not a real reply.
  • The CLI and localhost MCP expose subsets of the desktop workflows.

# Map exploration preview

Open `preview.html` to explore the proposed controls using synthetic data.
No dependencies, remote requests, Git operations or file writes are performed.

Code supports folder collapsing and direct-neighbor focus. History and People
show Scope and Load more controls. Stop invalidates the simulated pending read.
Export reviews Mermaid source as text; the Save button is a design simulation.
At compact widths Details opens a drawer. The page itself can scroll vertically.

This preview precedes the native Rust implementation. Native acceptance uses
`tools/tests/test-mcp-map-exploration.cjs` with disposable local repositories.
